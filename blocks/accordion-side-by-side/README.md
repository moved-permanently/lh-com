# accordion-side-by-side

Custom **accordion** block. Purpose: link-list accordions whose items sit side by side in equal columns on desktop.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per item. Cell 1: title (plain text or a heading; an authored heading keeps its level and wraps the toggle). Cell 2: panel content, usually a bulleted list of links (additional cells are appended to the panel). Items sit in equal columns from 993px (any number), stacked below; all start collapsed and toggle independently. A row without panel content renders its title only, not collapsible. Empty rows are ignored; zero-width characters are removed; external links open in a new tab.
