# hero-card-overlay

Custom **hero** block. Purpose: promotion stage: full-bleed background image with a solid dark text card overlaid on the left.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 column. Row 1: background image. Row 2: optional eyebrow paragraph, heading (H1 or H2), optional text, CTA link(s). The first image anywhere is the background; everything else goes into the card, so cell order and count do not matter.

## Supported variations

No variations.
