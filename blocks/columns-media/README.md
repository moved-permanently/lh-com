# columns-media

Custom **columns** block. Purpose: text beside media (image, several images, linked image or click-to-play video), one row per pair.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns, one or more rows (one row per text/media pair). Each cell is either media or text: a cell holding only pictures and links is media, any other cell is text, so text | text and image | image are also valid. Cell order sets the media side. Media cell: one image; or several images (shown side by side, e.g. photo + QR code; option stacked: one under the other, 40px apart); each image may be followed by its caption, a paragraph ending in `{caption}` (14px bold, 10px under the image; the cell stays a media cell); or a linked image (an image wrapped in a link, or an image with a bare link (link text = URL) in the same paragraph, which then wraps the image; a link with real link text stays a visible link); or a video: poster image plus a link to an .mp4 file, rendered as the poster with a play button (bottom left) that replaces it with an inline video with controls (looping). Playback settings follow the link in the same paragraph as a marker, any of `autoplay`, `muted`, `loop`, `controls`, `round-play-button`: `{autoplay muted loop}` (Lufthansa moving image) plays by itself, muted, looping, without controls or button, once it comes near the viewport (with reduced motion: a play button instead); `{controls round-play-button}` (Lufthansa video viewer) shows a 90px round play button in the middle of the poster and plays with controls, not looping, sound on. Without a marker: square button, controls, looping. The importer writes the source's settings. A video that stands alone on the live page (video viewer or moving image outside a column view: in the running text, a tab, a one-column view) is a block with a single row holding only the media cell, over the full content width (/de/en/carry-on-baggage 'How to stow' 1249px at 1440, /de/en/100-years/crane). The play button's accessible name is the .mp4 link text when it is not a URL, otherwise the locale default 'Play video' (EN) / 'Video abspielen' (DE). An embed link (YouTube or Lufthansa in-flight entertainment widget URL, see blocks/embed) alone in a media cell, or alone in its paragraph after the text of a text cell, shows the player (YouTube 16:9 over the cell width: /de/en/traveltricks 'Like a snap' text | video 615px at 1440; /de/en/lufthansa-business-class-on-long-haul-routes video | empty cell: an empty cell beside a player keeps its column from 768px and is not shown on mobile). Videos and embeds are built by scripts/media.js, styled by styles/media.css. Text cell: headings, paragraphs, lists (a paragraph or list ending in `{limited-width}` takes two thirds of the cell from 1025px, Lufthansa `.richtext.limited-width`: /de/de/additional-services intro 608px beside the jump links), links (bold link = primary button, italic = secondary); an image (or linked image) that opens a text cell is the cell's picture over the full cell width (image + heading + text side by side: /de/de/kinder-an-bord 'Fliegen mit Baby' / 'Fliegen mit Kind'), linked images after the text are badges. Option wide-media: media column 75%, text 25% from 768px, media shown first on mobile. Option sidebar (Lufthansa `.airem-sidebar`): the first cell 75%, the second 25% from 768px whatever they hold (text | links, text | image, image | text), 40px above the row and, from 768px, 20px below its taller cell, a text cell counting 26px below its last line and a media cell 40px below the image (Lufthansa `.image .image-wrapper` margin; 46px / 60px in all), 20px above and 36px below on mobile, stacked in the authored order with 40px between; an empty second cell keeps its column. Sidebar with option padded (a sidebar that is the only content of a Lufthansa one-column view of its own, `.column > .column-view:only-child { padding: 3.2rem 0 }`; the importer sets it): 32px more above and below, 24px less above when the block opens its section; with before-padded (the next live section is padded) the section padding (20px, 40px from 768px) below as well (/de/en/100-years 'Under the symbol of the crane': text to image 140px, image to the next image 157px at 1440). A link alone in its paragraph whose target is on the page (`#heading-id`) shows a down arrow (jump links next to the intro: /de/de/additional-services, /de/en/boeing787). Option slider (Lufthansa column view with carousel behaviour): below 1025px several images in one media cell are slides, one image at a time, with dots under it (68px below the image) that show the other images; from 1025px they stay side by side (/de/en/online-check-in app teaser: photo, QR code on the second slide). Option ratio-NN (AirCore running text with an image floated beside it, `<img style="float: left" width="60%">`): the media cell floats NN% of the row wide at every width with the text wrapping around it, 50px to the text, 20px below (`ratio-60`: /lhg/de/en/dest/cy/new-york 'Lufthansa Premium Economy' 542px image at 1440; a media cell after the text floats right); on AirCore pages the block keeps to the running text column (75%). On Insights articles the block sits in the article card (83.333%, centred) with its text at 80% of the column. Option stacked (Lufthansa Insights article galleries, several image components in one column item): the images of a media cell one under the other, each with its caption, 40px from a caption to the next image (/de/en/articles/explore-the-world/picture-perfect-austin: 1:1 image | two 1920x823 images). Option media-first (Lufthansa Insights category list, `.blog-overview`): rows alternate text | image and image | text as authored, the image above the text on mobile, 100px between rows (30px on mobile), 40px inset from 1025px; a list that opens a text cell shows as tag chips (/de/en/articles/explore-flying: 6 article rows 582 | 582 at 1440). Option padded (Lufthansa column view that is a component of its own, `.section-content .column > .column-view:only-child { padding: 3.2rem 0 }`; the importer sets it when the column view has no title and is not grey): 32px above the first row, 8px below the last one, which with the wrapper spacing makes 32px to the next component (56px at the end of a section) (/de/de/kinder-an-bord: intro text to the first image 60px like live). Without an option the columns are equal and mobile keeps the authored order. Rows or cells left empty are dropped; a row with a single cell spans the full width; rows with more than two cells get equal columns from 1025px and two per row from 768px (Lufthansa three/four-column views, `.col-md-6.col-lg` items: /de/en/travelling-with-special-requirements at 768, 44px between the wrapped rows). External links open in a new tab. Section style 'grey' (Section Metadata) gives the grey band..

## Supported variations

| Variation | Option class |
| --- | --- |
| Wide media (75/25) | `wide-media` |
| Sidebar (first cell 75%, second 25%) | `sidebar` |
| Slider (several images in a media cell: slides with dots below 1025px) | `slider` |
| Alternating rows, media above the text on mobile, tag chips (Insights category list) | `media-first` |
| Floated media cell NN% wide, text around it (AirCore) | `ratio-NN`, e.g. `ratio-60` |
| Several images in a media cell one under the other (Insights galleries) | `stacked` |
| Column-view spacing: 32px above, 32px to the next component (Lufthansa column view in an AEM section) | `padded` |
| Sidebar in a one-column view of its own: the column view's 32px above and below the sidebar; before-padded adds the next section's top padding | `sidebar padded`, `sidebar padded before-padded` |
| Images of a column view nested in each cell (icons: an image opening a text cell is one of N nested columns wide, the whole cell below 768px, half from 768px; 32px above, 52px (62px on mobile) to the text; empty cells keep their column: /de/en/shopping, passengers-with-sensory-impairment app badges) | `nested-2`, `nested-3`, `nested-4` |
