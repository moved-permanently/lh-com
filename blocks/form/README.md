# form

Custom **form** block. Purpose: render-only contact and feedback form built from an authored field table; nothing is ever sent.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 7 columns: Label | Type | Name | Required | Options | Help text | Placeholder. The first row is the header (English or German header words such as Label/Bezeichnung, Type/Typ, Name, Required/Pflichtfeld, Options/Optionen, Help text/Hilfetext, Placeholder/Platzhalter); columns are matched by header name, so they may be reordered or left out. Without a recognizable header row the default order above is used. Then one row per field, in order. Type is one of: step (starts a new step band: Label = step headline, Help text = step description; the following fields go into that step's white card), text, email, tel, number, date, textarea, select (Placeholder = disabled empty first option), radio, radio-cards (radio group shown as selectable cards), checkbox (single checkbox without Options, a checkbox group with Options), file (Options may list accepted types such as .pdf, .jpg and the word multiple; files are only listed, never uploaded), note (static text: the Label cell, links and formatting kept), submit (Label = button text, empty = locale default Submit/Absenden), label (UI text override, see below). Unknown types render as text inputs. Name: the field name; when empty it is derived from the Label and made unique. Required: yes, ja, true, x or required (any case) makes the field required; anything else or empty is optional. Options: comma-separated value=Label pairs or just Label (value derived from the label), or one option per paragraph/list item. Help text renders under the field and may contain links. Placeholder is the input placeholder or the select's empty first option. Rows with missing cells use empty values, extra cells are ignored, empty rows are skipped. UI text overrides: a row with Type label, Name = key and Label = text. Keys and defaults (English / German): sent message = This is a preview form. Nothing has been sent. / Dies ist ein Vorschauformular. Es wurden keine Daten gesendet.; submit label = Submit / Absenden; required marker = * / *; required text (screen-reader text for required groups) = (required) / (Pflichtfeld); file none label = No file selected / Keine Datei ausgewählt; checkbox group error = Please select at least one option. / Bitte wählen Sie mindestens eine Option aus. Type feedback-modules (lufthansa.com feedback form; Name = the name of the topic select, e.g. topic): after a topic is chosen, the block shows that topic's sections, as the live dcep-feedback-form does: which modules a topic has comes from /service/api/catalogs/feedbackForm (the select's option values are its catIDs), every text from /service/api/labels/feedbackform and labels/common (live, else the recordings, scripts/lh-data.js; data-lh-source on the block), followed by the submit button (page.default.submit). Rendered modules (blocks/form/feedback-modules.js): A feedback text, B/O/P contact data (without the address and phone part), G ticket number or booking reference, H feedback ID, I attachments, J browser and operating system, L PIR number, M bank account; F renders nothing (as on the live site); flight data, refund and voucher modules are not rendered. Render-only: the form has no action, submitting is always prevented and nothing is sent or uploaded; a valid submit shows the sent message, an invalid one shows inline messages and focuses the first invalid field..
