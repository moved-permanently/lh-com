# columns-logos

Custom **columns** block. Purpose: side-by-side columns, each a small heading over an inline row of logo or icon links.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row, one cell per column (more rows add more columns). Each cell: heading, then linked logo images or :icon: tokens. Image alt text names each logo; icon-only links are named from the icon name. Plain text links are kept as text items.

## Supported variations

No variations.
