# app-links

Custom block. Purpose: the app's links, each with its arrow. It belongs only in app screen documents under `/content/mobile/lh/<lang>/`, which lh-edge turns into the app's JSON (`tools/workers/lh-edge/SDUI.md`). This rendering only shows authors what the app shows (each item's tracking label as a small grey caption); lh-edge reads the document itself, so it never changes the app.

## Authoring (Document Authoring)

One row per link: cell 1 the link (text and target), cell 2 the tracking label, cell 3 (optional) the title the app shows while the target loads.
