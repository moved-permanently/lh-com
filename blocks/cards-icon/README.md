# cards-icon

Custom **cards** block. Purpose: row of compact link tiles with a centred icon over a bold label.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tile. Cell 1: icon (:icon-name: token or small image). Cell 2: label linked to the target. Cells may be merged or missing: the first icon/image, first link and the text of the row are used.

## Supported variations

| Variation | Option class |
| --- | --- |
| Service tiles (Lufthansa a.teaser.usp, /additional-services): no box, 88px icon image centred over a regular label (20px to 24px), equal columns 20px apart: 1 per row, 2 from 768px, 3 from 1025px | `usp` |
| Four per row from 1025px (with `usp`) | `four-up` |
