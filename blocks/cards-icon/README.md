# cards-icon

Custom **cards** block. Purpose: row of compact link tiles with a centred icon over a bold label.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tile. Cell 1: icon (:icon-name: token or small image). Cell 2: label linked to the target. Cells may be merged or missing: the first icon/image, first link and the text of the row are used.

## Supported variations

No variations.
