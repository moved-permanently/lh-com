# cards-steps

Custom **cards** block. Purpose: numbered process steps.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 column, one row per step (merged or split cells are combined). Content in order: the step number as the first paragraph ("1", "2."; optional, generated from the position when omitted), H3 title, description paragraph(s), optional CTA: a last paragraph that holds only a link is rendered as an arrow link. Empty rows are skipped. No label rows; all texts are authored.

## Supported variations

No variations.
