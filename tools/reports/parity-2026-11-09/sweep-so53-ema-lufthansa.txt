# ema-lufthansa, standing order 53 (2026-11-20): do ema-adobe's lufthansa.com rules in the shared code move the other sites?
# Sites: Brussels, ITA, Discover, SWISS, Group for Business and Austrian, all on the same code (styles/styles.css, blocks/).
# What decides it:
#   - Every rule so far is scoped to body.brand-lufthansa.
#   - scripts/brand.js loadBrandTheme adds that class only when the page has no brand meta (brandOf: the "brand" meta naming
#     a known brand). A page with its brand meta gets body.brand-<brand> and never brand-lufthansa.
#   - So (1) a census of every served document of the six sites reads its brand meta and whether its markup holds a rule's
#     targets; (2) the documents that hold the targets are rendered.
# Renders:
#   - On each brand host, 1440 x 900 and 390 x 844, three browsers at once, one page at a time each (full Chrome, Liberation
#     Sans for Arial, airline hosts refused), order 50's load and checks.
#   - Each page is rendered as served, counting in the page how many elements each rule's selector matches (and the same
#     selector without the brand scope, to show the targets are there), and again with styles/styles.css as it was before
#     the pushes.
#   - Brussels, ITA and Discover are also set against order 50's renders of the same page-widths (sw-<brand>.jsonl).
#     SWISS, Group for Business and Austrian had no order 50 or 52 renders; for them the before-push stylesheet is the base.
#   - A finding: a height more than 1 % off, or a flag the other render has not.
# A finding on 3 or more documents of a brand would get its scoping as a proposal for ema-adobe here. Nothing was changed
#   in the shared code by this order; nothing uploaded, previewed or published.
