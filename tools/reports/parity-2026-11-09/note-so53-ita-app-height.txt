#   The Columns Media picture of the same section keeps its 350 px while unloaded: its block sets its size. So only pictures in default content collapse.
#   Effect: every default-content picture below the first screen takes no space until it loads. Page heights, anchors and parity captures then depend on load timing, on every brand; www reserves the space.
#   A fix (ema-adobe's call, with its own census across brands): let the width attribute size the image, for example "main .default-content-wrapper > p > picture img { width: 100%; }" or no width:auto for images with a width attribute, so the aspect ratio reserves the box before loading.
